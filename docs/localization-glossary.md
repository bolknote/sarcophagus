# Глоссарий русской локализации Sarcophagus

Этот файл фиксирует термины и стиль активного перевода `locales/ru.lua`. Старый файл `locales/ru_legacy.lua` является только источником черновых вариантов.

## Основные термины

| English | Русский | Примечание |
|---|---|---|
| The Machine | Машина | С прописной буквы, когда речь идёт об уникальном персонаже/устройстве |
| power | энергия | Показатель и ресурс для преобразований Машины |
| grit | выносливость | В узком HUD допустимо сокращение «Силы» |
| body | тело | Состояние тела персонажа; не заменять автоматически на «здоровье» |
| clean / filth | чистота / грязь | `filth` в коде хранит показатель чистоты в обратной форме |
| faith | вера | Показатель молитвы |
| Ice Shards | осколки льда | Стартовый ресурс |
| legacy support | наследство | Бонусы метапрогрессии при создании нового мира |
| quest | задание | В репликах допустимо «квест», если это часть шутки об игровых условностях |
| crafting | крафт / изготовление | «Крафт» — в коротких элементах UI, «изготовление» — в связном тексте |

## Непереводимые игровые маркеры

Идентификаторы `#dig`, `#cut`, `#chop`, `#smash`, `#pierce`, `#water`, `#oil`, `#vinegar`, `#seed` и знак `≈` сохраняются без перевода: они являются частью игровых правил и разметки.

## Стиль

- Обращение к игроку — нейтральное либо на «вы», без указания рода.
- Грубый, абсурдистский и самоироничный тон оригинала сохраняется, но не усиливается переводчиком.
- Для динамических названий используются нейтральные конструкции: «Получено: _1_», а не формы, требующие рода предмета.
- Placeholder-ы `_1_`, `_2_` и цветовые теги `{#ffffffff}` нельзя изменять или переставлять без проверки контекста.
- В коротких панелях важнее читаемость и стабильная ширина, поэтому допустимы понятные сокращения.
